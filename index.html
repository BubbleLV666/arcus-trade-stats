Trading stats for any address on Arcus

Paste an address — the site queries the public Arcus API directly and shows equity, PnL, volume, fees, positions with estimated liquidation prices, maker/taker split, per-market breakdown, funding, deposits and leaderboard rank. No keys or sign-in needed; the address is sent nowhere except the Arcus API.

Arcus points are not shown per address: their API returns them only to the wallet owner after sign-in.

The table lists the top 100 (the API's limit per list), but any address can be looked up: use Find or open it in My stats — its rank is shown even if it is far outside the top 100, e.g. #2,000 of thousands. Rankings exist for 24 hours, 30 days and all time. Realized PnL is the exchange's closedPnl sum — it excludes unrealized PnL and funding. The data comes from an hourly rollup and can lag by up to an hour. Click a header to re-sort these 100 rows.

Unofficial project, not affiliated with Arcus. Data comes from the public API api.arcus.xyz; it may lag or contain exchange errors. Liquidation estimates are approximate.

This site connects to the Arcus API

This site reads data directly from the public Arcus API (api.arcus.xyz), from your browser and your IP address.

If you open many wallets in a short time or refresh the page very often, the request limit can be exceeded and Arcus may temporarily refuse requests from your IP: the page then shows no data or an error. This usually goes away after a few minutes.

This is an unofficial site, not affiliated with Arcus.
